# Airspace Alpha Signal Catalog

Signals are ranked by defensibility, not visual appeal.

## Tier 1: core moat
### Counterparty convergence
Two or more aircraft attributed to economically related entities co-locate within a defined geofence and time window.

### Route novelty
An aircraft visits a destination outside its historical route distribution.

### Repeat campaign
A normally rare entity-place pairing repeats several times within a short window.

### Dwell anomaly
Ground time differs materially from that aircraft's own destination-specific history.

### Market dislocation
Physical-world evidence changes materially while linked prediction-market consensus remains largely unchanged.

## Tier 2: corroboration
- SEC disclosure proximity
- public-news absence / presence
- executive / corporate-facility proximity
- institutional event / conference proximity
- federal contract / award context
- supply-chain facility proximity

## Tier 3: suppressors
These reduce attention:
- weather diversion probability
- fuel / technical stop likelihood
- known maintenance base
- habitual commute
- charter/fractional reuse ambiguity
- ownership confidence below threshold
- destination with no economically relevant entity
- already-public event

## Provenance
Every signal stores:
- exact source timestamps
- source license
- entity-resolution confidence
- feature version
- raw evidence references
- alternative explanations

A signal score without provenance is not an Airspace Alpha signal.
