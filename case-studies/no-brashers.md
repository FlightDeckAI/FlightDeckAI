# No Brashers: turn a real friction point into a useful tool

**Public web product · Father-daughter project · Aviation**

No Brashers collects checklist prompts, phrase references, and debrief notes in a clear pilot workspace. It grew from the flying and learning Lloyd and Lilli share.

## Evidence available today

- [The public website](https://nobrashers.com/) and its web workspace.
- [AOPA's January 28, 2026 article](https://www.aopa.org/news-and-media/all-news/2026/january/28/flight-lessons-inspire-a-new-pilot-tool) about the project.

## The product lesson

Start with a specific moment of friction. Reduce what the user has to search through. Make completion deliberate. Capture what should be discussed afterward.

The watch presentation is a concept with device validation pending, separate from the available web product. AOPA coverage is press coverage, not an endorsement or a measured safety result.

The process behind this portfolio is to listen, build a bounded tool, expose it to real feedback, and improve the interaction.
